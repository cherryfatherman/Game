# 그림 주문 · 이야기 장면의 인물

여는 장면("그 밤")과 1구역 장면에 나오는 세 사람이다. 생김새는 아직 정하지 않았으므로 **제안**이다. 뽑아 보고 마음에 드는 것을 기준 그림으로 삼는다.

## 뽑는 법
1. 제미나이 **새 대화**에 `art/ui/영웅-얼굴.png`(남자 기사 얼굴)를 올린다. 그림체를 맞추는 기준이다.
2. 아래 문구를 하나씩 붙여 넣는다. 한 번에 한 사람.
3. 나온 그림을 대화에 올린다. 장면 카드에 넣는 일은 코드로 한다.

## 미로 (아홉 살 동생)

```

```

Draw a new character in exactly the same drawing style as the attached image (modern Korean webtoon illustration, sharp clean linework, crisp cel shading). Do not copy the attached character; only match the style.

CHARACTER: the Witch, an ageless woman who looks neither young nor old. She is not evil and not kind: calm, quiet and very lonely.
