# 기획 · 동료, 무기, 퀘스트, 과금

> **제안 · 아직 확정 전 (날짜 2026-11-15)**
> 네 문서 모두 제안이다. 기준은 `가이드라인.md`이고, 어긋나면 가이드라인이 맞다. 확정된 것은 가이드라인과 도감으로 옮겨 적는다.

## 한눈에 보기

- 힘은 네 가지를 곱해서 나온다: **무기 × 골드 강화 × 무기 보유 효과 × 동료.**
- 돈을 안 써도 날마다 **무기 30번, 동료 10번**을 뽑는다. 보통 9달, 가장 늦어도 1년 안에 마지막 무기까지 간다.
- 돈은 속도만 바꾼다. 월정액 1.3배, 모두 사도 2.6배.
- 숫자는 `tools/기획계산.py`로 확인했다. 사람이 해 본 값은 아니다.

## 중요한 숫자

| 항목 | 값 |
|---|---|
| 무료 하루 뽑기 | 무기 30번 · 동료 10번 |
| 무료 하루 다이아 | 50개 (광고를 보면 +30) |
| 다이아 값 | 무기 뽑기 1번 10개 · 동료 뽑기 1번 30개 · 옷 600개 |
| 돈으로 치면 | 1,200원 = 다이아 300개 = 무기 뽑기 30번 |
| 동료 수 | 15마리 (5등급 × 3) |
| 무기 공격력 | 목검 10 → 기억의 검 27,000 |
| 강화 (무기·동료) | 1레벨에 처음 값의 20%, 최대 10레벨 (3배) |
| 골드 강화 | 한 번에 무기 공격력의 10% |
| 무기 보유 효과 | 한 자루 2 · 4 · 8 · 15 · 30% (등급 순) |
| 동료 장착 효과 | 10 · 20 · 40 · 70 · 120%부터 (등급 순) |
| 동료 보유 효과 | 한 마리 1 · 2 · 4 · 8 · 15% (등급 순) |
| 월정액 | 4,900원 · 날마다 무기 10장, 동료 3장, 다이아 30개 |
| 시즌 패스 | 9,900원 · 8주 |
| 다이아로 사는 뽑기 상한 | 하루 무기 30번 · 동료 10번 |

### 계산 도구

```
python3 tools/기획계산.py 뽑기     # 무기·동료 뽑기: 며칠 걸리나 (3분쯤 걸린다)
python3 tools/기획계산.py 성장     # 공격력으로 몇 구역까지 가나
python3 tools/기획계산.py 성장 4   # 구역 배수를 4배로 바꿔서 한 번 더
```

무기 뽑기 규칙은 `tools/뽑기계산.py`와 같고, 결과도 무기 도감의 표와 같게 나온다.

## 기준 문서와 어긋나거나 손봐야 할 곳

| 곳 | 무엇 |
|---|---|
| 가이드라인 "따라다니는 친구" | 이 문서들은 "동료"라고 썼다. 하나로 정해야 한다 |
| 가이드라인 "최대 데미지 9999만" | 구역마다 5배면 10구역에서 큰 스킬이 한도에 걸린다. 4배면 걸리지 않는다 |
| 가이드라인 강화 "한 번에 +1" | "한 번에 무기 공격력의 10%"로 제안했다. 목검일 때는 똑같이 +1이다 |
| 설정집 "도른의 검으로 10화까지 싸운다" | 뽑기에서는 희귀 무기다. 4구역 보스 보상과 칼 모양 꾸밈으로 풀기를 제안했다 |
| 무기 도감 "수습기사의 검 = 루가 들고 떠난 검" | 처음 무기는 목검(10)으로 잡았다 |
| 가이드라인 "소환권" | 가이드라인 5장의 "뽑기"에 맞춰 "뽑기권"으로 썼다 |
| 가이드라인 3장 "위에서 내려다보는 들판" | 같은 장의 가로 화면·여러 층 발판과 어긋난다. 동료 스킬의 "같은 층"은 발판 방식에 맞췄다 |
| 보고서의 다이아 값 (1,200원 = 100개) | 뽑기가 들어와서 1,200원 = 300개로 다시 잡았다 |
| 보고서의 "쉬는 동안 보상 늘리기" 판매 | 골드를 파는 셈이라 뺐다 |
| 설정집 "얽힌 실" | 동료의 새 이야기 세 줄(흰 토끼, 수달, 아기 용의 알)은 확정되면 여기에 먼저 적는다 |

## 정해 주실 것 (네 문서에서 모음)

### 동료
1. 동료 수를 15마리로 할지. 권함: 15마리.
2. 이름을 "동료"로 할지 "친구"로 할지. 권함: 동료.
3. 데리고 다니는 동료를 한 마리로 할지. 권함: 출시 때는 한 마리.
4. 새 이야기 세 줄을 설정집에 넣을지. 권함: 넣는다.

### 무기 능력치
1. 골드 강화를 "무기 공격력의 10%"로 바꿀지. 권함: 바꾼다.
2. 구역 배수를 5배로 둘지 4배로 낮출지. 권함: 4배.
3. 처음 무기를 목검으로 할지 수습기사의 검으로 할지. 권함: 목검.
4. 도른의 검을 4구역 보스 보상으로 한 자루 줄지. 권함: 준다.

### 퀘스트
1. 일일 퀘스트를 "미로의 편지"로 할지. 권함: 한다.
2. 길잡이 퀘스트에서 무기 뽑기권 100장을 줄지. 권함: 준다. 1구역 시간을 다시 잰다.
3. 구역 퀘스트에서 옛 구역으로 돌아가게 할지. 권함: 구역마다 하나쯤.
4. 못 한 날의 일일 퀘스트를 메워 줄지. 권함: 메워 주지 않는다.

### 과금
1. 다이아로 사는 뽑기에 하루 상한을 둘지. 권함: 둔다.
2. 뽑기권과 다이아를 따로 둘지. 권함: 따로 둔다.
3. 값을 이대로 시작할지. 권함: 이대로 시작하고, 사람들이 해 본 뒤 고친다.
4. 보상 광고를 넣을지. 권함: 웹에서 되는지 확인한 뒤 정한다.

### 가장 먼저 정하면 좋은 것
구역 배수(5배냐 4배냐)다. 이것이 정해져야 2구역을 만들 수 있고, 무기 표와 "이야기 끝을 몇 달째에 보나"가 따라 정해진다.
